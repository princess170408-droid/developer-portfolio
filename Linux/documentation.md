# Linux Command Documentation

## Introduction
Linux is an open-source operating system.

## Commands Used

1. pwd - Displays the current directory.
2. ls - Lists files and folders.
3. cd - Changes directory.
4. mkdir - Creates a directory.
5. touch - Creates an empty file.
6. cat - Displays file contents.
7. cp - Copies files.
8. mv - Moves or renames files.
9. rm - Removes files.
10. whoami - Displays the current username.
11. date - Displays date and time.
12. uname -a - Displays system information.
13. df -h - Displays disk usage.
14. free -h - Displays memory usage.
15. chmod - Changes file permissions.

## Conclusion
Linux commands help users manage files,
directories and system information.
